# First-generation AELMDB reference

Frozen implementation retained for behavioral comparison, regression
reproduction and selective feature recovery.  It is not an ancestor of the
canonical four-patch AELMDB derivation.

Two capabilities still to be recovered from this reference into the current
stage-04 architecture are the optimized multi-64-bit-limb hash-sum arithmetic
and the window/rank-range query API.  Code should be imported selectively;
first-generation capture/replay/repair maintenance must not be reintroduced.
